Executive Summary & Mathematical Problem Formulation\n\n### 1.1 Objective & Graph Formalism\nThe primary objective of this benchmark is the complete spatiotemporal reconstruction of embryonic cell lineages during early zebrafish development. Multi-daughter division ($\text{deg}^{+} \\ge 3$) is biologically non-viable and absent in the ground truth.\n\n### 1.2 Metric Matching Mechanics & Physical Distance Function\nPrediction quality is assessed using physical distance in anisotropic microns ($\\mu\\text{m}$). The diagonal voxel-to-physical scaling matrix is defined as:\n$$\\mathbf{S} = \\text{diag}(s_z, s_y, s_x) = \\text{diag}(1.625, 0.40625, 0.40625) \\quad (\\mu\\text{m}/\\text{voxel})$$\nThe anisotropic physical distance between any two centroids $\\mathbf{p} = (z_p, y_p, x_p)$ and $\\mathbf{q} = (z_q, y_q, x_q)$ is given by:\n$$d_{\\mathbf{S}}(\\mathbf{p}, \\mathbf{q}) = \\|\\mathbf{S}(\\mathbf{p} - \\mathbf{q})\\|_2 = \\sqrt{1.625^2(z_p - z_q)^2 + 0.40625^2(y_p - y_q)^2 + 0.40625^2(x_p - x_q)^2}$$\n\nA predicted cell $\\hat{u}$ matches a ground-truth cell $u^*$ at frame $t$ if and only if:\n$$d_{\\mathbf{S}}(\\hat{\\mathbf{p}}, \\mathbf{p}^*) \\le R_{\\text{gate}} = 7.0\\ \\mu\\text{m}$$\nIn voxel coordinates, this $7.0\\ \\mu\\text{m}$ physical tolerance translates to:\n* Axial radius: $\\Delta z_{\\text{tol}} = 7.0 / 1.625 = 4.31$ slices.\n* Lateral radius: $\\Delta r_{xy,\\text{tol}} = 7.0 / 0.40625 = 17.23$ pixels.\n\n### 1.3 The Quadratic Edge Recall Bottleneck\nAn edge $e = (u, v)$ is matched if and only if both endpoints $u$ and $v$ are correctly matched within $7.0\\ \\mu\\text{m}$.
